原路径：首页菜单 → 选择物种 → 大象页拍照 / 相册 / 录视频 → 图片结果或视频结果。

交接记录点名的最后一批游客改动（2026-11-10）：处理页精简、待复核进入结果页、弱网与超时继续查询、防重复提交。自动查询约 90 秒结束，之后继续查原来的任务。

## 3. 识别链路

他的遗留评估（`services/core-api/docs/legacy-assessment.md`）把你现在的写法当成不能上线的原因，并据此重做，而不是改 `elephantJava`。

| 环节 | 你的原项目 | 交接包 |

| 游客识别 | `app.js` 直连 `https://recognize.liangzhihuamei.xyz` 的 `/predict`、`/predict-video` | 只调 Core API。离线预览不打真实识别 |
| 写记录 | 再 `POST {javaApiUrl}/open/recognition-records`，客户端自带预测名和置信度。`javaApiUrl` 仍是 `localhost:8082` | 服务端建任务。机器结果要绑任务、输入摘要和模型版本 |

| 等待 | 当前页 loading | 可离开页面，从「最近识别」恢复，重试不新建单 |
| 业务后端 | Spring Boot + MySQL `animal-recognition`。接口：用户、物种、个体、摄像头、识别记录、上传 | Python Core API。本地可内存；正式设计是 PostgreSQL |
| 管理端 | Vue：登录、物种、个体、摄像头、识别记录、个人资料 | HTML：运营总览、个体主数据、识别事件、复核队列、设备只读、权限审计 |

| 模型 | 现有 Python 服务。PRD 提到 17 个已知个体可作验证起点 | 推理与模型平台分开。权重和数据集不在包内 |
